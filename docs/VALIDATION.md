# Validation evidence

Initial local validation on 2026-10-13, Windows, Python 3.12 and Node 24:

- Python API and retrieval tests passed; tenant isolation, revisions, duplicate/stale events, citation rejection and empty-evidence abstention are covered.
- Angular production compilation passed; initial application transfer estimate was about 40 kB.
- Two Playwright journeys passed against the real local API: desktop retrieval/citations/abstention/evaluation and mobile document upload/layout.
- Screenshots were generated by the browser tests, not design mockups.
- Compose configuration and Kubernetes Kustomize rendering passed local validation.

The host Docker engine reported unavailable virtualization, so service integration is executed separately in the GitHub Actions `integration` job. The workflow uses actual PostgreSQL, Kafka and Mongo containers and a black-box smoke test. The release's CI run is the authoritative result for that path.

No local model server was active during the initial validation. The LLM HTTP adapter has provider-response contract tests, including token usage and invalid citations. This is not a measured evaluation of a real model's answer quality. The default demonstrated answer mode is extractive.

The four-case sample retrieval suite is visible and synthetic. It is a regression smoke, not an unseen benchmark. This project makes no economic or production-scale claims.
